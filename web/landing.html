Boards

Drag a card, or never touch the mouse.

A Scrum board follows the running sprint. A Kanban board follows the flow. Every drag has a keyboard twin.

  • Drag and drop across and within columns, or the “Move to…” menu
  • Columns that hold several statuses, with WIP limits that warn
  • Kanban tidies away done work after the days you choose
  • On a phone, the board shows one column at a time

Backlog and sprints

Plan the sprint where the work already is.

Sprints and the backlog live in one list. Pull issues in, size them and start the sprint. When it closes, unfinished work goes where you choose.

  • Drag issues between sprint sections and the backlog
  • Edit summary, points and assignee right in the row
  • Unfinished work goes to the backlog, the next sprint or a new one
  • An epic panel to group and filter work

Issues

Every detail one click from the board.

Open an issue over the board, edit a field in place, and go back where you were. Filters live in the URL, so every view is a link.

  • Epics, stories, tasks, bugs and subtasks
  • Comments, labels, points, priority and parent
  • Filters by assignee, type, label and epic, plus project search
  • Shortcuts: c creates, j / k move, ? lists the rest

Import

Bring your work from your current tracker.

Upload a Jira or Linear CSV export. Check how statuses, people, sprints and issue types map before anything is written, then import in one click.

  • Summary, description, status, assignee, labels, points and parents come across
  • People are matched to members by email
  • Running the same file again skips what it already imported

AI agents

Give an AI agent the keys to your board.

Connect an AI assistant over MCP with an API token. It gets 38 tools to create and move issues, plan sprints and comment, with exactly your permissions.

  1. Create an API token from your account menu.
  2. Add santi to your AI assistant, with that token.
  3. Ask for what you need. It sees the boards you see.
  • Claude
  • ChatGPT and Codex
  • GitHub Copilot
  • Cursor

Works with Claude, ChatGPT and Codex, GitHub Copilot, Cursor, or any other MCP client.

View setup guide

  1. You: Move WEB-12 to Done and add a comment that QA signed off.

    Assistant: Done — I moved WEB-12 to Done and added your comment: "QA signed off."

  2. You: Create a subtask under WEB-12 for the changelog entry, and put it in the next sprint.

    Assistant: Created WEB-15, a subtask of WEB-12, "Write the changelog entry," and planned it into Sprint 4.

  3. You: What's left on the board for Sprint 4?

    Assistant: 7 cards: 2 in To Do, 3 in In Progress, 2 in Done. WEB-15 is in To Do.

Prefer a terminal? The same API drives the santi command line, scriptable end to end. 

$ santi login --url http://localhost:8080
$ santi issues create WEB --summary "Fix login" --type bug
$ santi issues move WEB-12 --status "In Progress"
$ santi sprints start WEB 3

# give an agent your boards
$ claude mcp add santi --env SANTI_URL=http://localhost:8080 \
    --env SANTI_TOKEN=santi_… -- santi mcp

Performance

Built in Rust, fast at any scale.

santi's server is Rust: axum and sqlx talking straight to PostgreSQL. Measured on 5,000 issues, 50 people and 20 sprints, the Scrum board answers in 6.7 ms and the backlog in 18.9 ms, both p95. CI counts the SQL statements of every hot request and fails the build if the count grows, so a new feature cannot quietly add a query as the backlog scales.

Self-host

Run it yourself in one command.

One container image and PostgreSQL. Migrations run on start, and your data stays on your machine.

  • Docker Compose locally, or a guide for hosting it for your team
  • HTTPS through the reverse proxy you already use
  • No telemetry, no seats to count
Terminal 
$ git clone https://github.com/emersonjds/santi.git
$ cd santi
$ docker compose up -d
# open http://localhost:8080

Questions

Is santi free?

Yes. Self-hosting is free forever: every feature, under the AGPL-3.0, with no limit on people or projects. The hosted Free plan at getsanti.app has no people or project limits either, and 2 GB of attachments. Team adds 100 GB, e-mail support and backups for US$ 19 a month per workspace, once billing opens.

Can I host it myself?

Yes, that is what it is built for. docker compose up -d starts the server and PostgreSQL on one machine. For a team, put HTTPS in front with a reverse proxy; the self-hosting guide covers it, plus a hosted platform.

How do I move my work over?

Export your issues as CSV from your current tracker and upload the file in a project under Settings → Import issues. You check how statuses, people, sprints and types map before anything is written. Importing the same file twice creates no duplicates.

Is my data safe?

When you self-host, your data stays in your own PostgreSQL database. Passwords are hashed with Argon2id, sessions use an HttpOnly, Secure cookie, and API tokens can be revoked at any time. Back up the database volume on a schedule; security reports go through the process in SECURITY.md.

Who owns my data?

You do. It is never sold or shared, and there is no tracking or analytics. From your account page you can download everything as JSON or delete your account, the rights the LGPD and the GDPR give you. The privacy policy has the details.

Is santi legal to use at my company?

santi is open source under the AGPL-3.0, which allows commercial use. The hosted instance follows Brazil's LGPD and Marco Civil da Internet and, where it applies, the GDPR. Read the Terms of Use and the Privacy Policy, or self-host it to keep everything under your own policies.

Can AI agents work with it?

Yes. santi mcp is an MCP server with 38 tools covering projects, boards, backlog, issues, comments and sprints. An agent acts with the API token you give it and sees exactly what that token's user sees.

What is on the roadmap?

Organizations, an issue history and sign-in with Google are next. Follow the project on GitHub to see what lands and to suggest what should come after.
