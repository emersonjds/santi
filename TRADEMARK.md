# Trademark policy

santi's code is free software under the [AGPL-3.0](LICENSE). The name **santi** and the santi logo
are trademarks of Emerson Silva, the project's maintainer. This policy explains how you can use
them. It does not limit anything the license allows you to do with the code.

## You can, without asking

- Run santi, unmodified or with configuration changes, for yourself, your team or your company,
  and call it santi.
- Say that your product or service works with santi, imports into santi or is built on santi
  ("Hosted santi by Acme", "Acme, powered by santi"), as long as it is clear you are not the
  santi project.
- Write about santi, teach it, make videos and talks, and use the logo to illustrate them.
- Keep the "santi" name and logo that the software shows, in an installation you run.

## You need to rename it

If you distribute a modified version of santi, or offer a modified version to others as a hosted
service, give it a different name and logo. Changes that only use settings santi offers
(configuration, your organization's name, features unlocked with a santi license key) do not
count as modifications here.

Keep the AGPL notices and the link to the source code that the license requires; that is a
license duty, separate from this policy.

## You cannot

- Present your product, fork or service as the official santi, or as endorsed by the santi
  project, when it is not.
- Use the name or the logo in a domain, company or product name in a way that suggests that.
- Change the logo or combine it with your own mark.

## Questions

Open a discussion on GitHub or write to the maintainer. When in doubt, ask: most uses are fine.
