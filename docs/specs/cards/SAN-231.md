(Claude, ChatGPT/Codex, GitHub Copilot, Cursor, Gemini and other MCP clients) create, move, plan and
comment cards through conversation.

  features, mixes CLI and MCP, and says "16 tools" (stale: `crates/santi-cli/src/mcp.rs` declares 36
  `#[tool(` attributes, `docs/mcp.md` lists 33 rows; take the real count from the code).

  Windsurf, Zed, JetBrains AI Assistant and OpenAI Codex CLI; stdio and Streamable HTTP; personal API
  tokens; the agent acts with your permissions; user text in answers is untrusted data.
- Landing rules: static HTML (`web/landing.html`), landing.css tokens, D39 budgets (JS ≤ 10 KB, CSS ≤
  10 KB gzip), PageSpeed 100, no third-party logos or "official integration" claims (trademarks);
  vendor names as plain text only. "Jira" never appears on the landing.
- The pricing section (SAN-221) sits after `#self-host`.
