# Card briefs

One file per card a user sees: `SAN-<n>.md`. Written by the design panel before the build.

- Questions: each open design question, the `product`, `ux` and `ia` votes, the `architect` challenge, the winner and the trade-off accepted.
- Acceptance: what the user can do, and every state (empty, loading, error, partial, long text, many items, no permission, phone 375px, dark theme, keyboard and focus).
- Out of scope: what belongs to other cards.
- Deviations: anything changed during the build, with the panel's answer.
