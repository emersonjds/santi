# SAN-151 — Colored label chips and a roomier issue Details panel

Owner (2026-10-18, screenshots of the issue dialog): label chips are all gray, give them color; the
Details panel is cramped (values squeezed, Sprint name truncated, Epic select clipped, label chips
wrap under the field name, empty space below the last row). Use the space better.

Facts today: the issue dialog is `sm:max-w-[960px]` (`widgets/issue-detail/issue-dialog.tsx:67`);
the body grid gives Details a fixed `19rem` column (`issue-detail.tsx:218`); each Details row is
`md:grid-cols-[5.5rem_minmax(0,1fr)]`, `md:min-h-8`, `gap-y-0.5` (`issue-fields.tsx:45-47`). Label
chips are drawn separately in `entities/issue/issue-card.tsx:37` (board card, first 2),
`widgets/backlog/backlog-row.tsx` and `features/edit-labels/labels-picker.tsx:53` (gray, removable).
Labels are plain strings per issue; label entities with colors are SAN-103 (backlog). Tokens: D36
(`web/src/app/styles`). Reuse a shadcn/template component first (Badge exists in `shared/ui/badge.tsx`).

## States (ux)

- Empty labels: the Labels row shows only the "Add label" trigger, no chip, no placeholder text.
- Many labels: chips wrap to more lines in the Details value column; card and backlog row keep "first 2 + N" (`LabelChips`), Details shows every chip.
- Long label: the chip name truncates at its size's max width (compact `max-w-20`, default `max-w-48`), `title` holds the full text.
- Long sprint/epic name: the select shows what fits with the browser's ellipsis, `title` holds the full name, the open picker lists it whole.
- Unassigned: Assignee shows "Unassigned", "Assign to me" stays visible for the current member.
- Editing a field: the ghost control shows border and background on hover/focus (`GHOST`); no layout shift on commit.
- Error under a field: red text directly under that field (`Field`), not a toast.
- Read-only archived project: controls `aria-disabled` with the archived note (`WriteLock`); chip remove buttons stay in place, `aria-disabled` and inert through `lockedButton` like every locked control (SAN-70), instead of disappearing.
- 375px: single column, full-width controls, 44px targets, chips wrap, no sideways scroll.
- Dark: chips use the dark `--label-*` values; the name → hue mapping is the same in both themes.
