# SAN-101 — Labels picker

Owner: the Labels field is a free text box; offer default words, let people pick them and keep them side by side.

## Questions

| # | Question | product | ux | ia | Winner (architect) |
|---|---|---|---|---|---|
| 1 | Defaults | seed real labels per project | — | hard-coded suggestions | **Hard-coded suggestions** in the web client (labels are strings on issues; there is no table to seed): `bug`, `feature`, `frontend`, `backend`, `mobile`, `infra`, `design`, `docs`, `tech-debt`, `security`, `performance`, `blocked`. A suggestion becomes a real label once used. Per-project defaults and pt-BR: SAN-103 / SAN-93. |
| 2 | Order and case | keep case | — | alphabetical, selected first | **Selected first, then the project's labels A–Z, then unused defaults**; case kept as typed (server rule). |
| 3 | Pattern | — | chips + "+" popover with cmdk search | — | **Chips + "Add label" button opening a popover** with a search list (`shared/ui/command.tsx`, `popover.tsx`), like the board filter's multi-select. |
| 4 | Saving | — | each add/remove at once, optimistic | — | **Each change saves at once**, optimistic with rollback and an error message. |
| 5 | Create | — | "Create label <text>" row when no match | — | **Create row** when the text has no case-insensitive match and is valid (no whitespace, ≤ 50 chars); invalid text shows the reason and no create row. |
| 6 | Surfaces | issue view + create dialog | — | + cards and rows | **Issue view and create dialog** get the picker; **board cards and backlog rows show up to 2 label chips + "+k"**. Board filter stays as is. CLI/MCP keep `--label`. |
| 7 | Removing | x + Backspace, no undo | x + Backspace on empty search | — | **x on each chip; Backspace in the empty search removes the last**; no undo (re-add). |
| 8 | Management | — | — | separate card | **SAN-103**: rename, merge, delete, colors. |

## Acceptance

- Keyboard: trigger is a button (`aria-haspopup="listbox"`); arrows move, Enter adds, Esc closes and returns focus to the trigger; a polite live region announces "Label X added/removed".
- Phone 375px: chips wrap, 44px targets (chip remove and trigger), search input 16px, popover fits with a 16px gutter.
- States: no labels yet (defaults only), many labels (search filters, list scrolls), long label (chip truncates, full text in `title`), saving, error with rollback, duplicate pick is a no-op, read-only viewer sees chips without controls.
- Cards and backlog rows: at most 2 chips then "+k"; no layout shift; D39 board INP budget holds.
