# SAN-136 — Comment thread UI: spacing, composer and per-comment actions

Baseline: `behavior/editor-and-comments.md` ED-29..ED-45 (comment area, quick replies, edit,
delete, rights, reactions, replies, views, ordering, permalink) and OQ-9..OQ-15 there. The editor,
format and mentions shipped in SAN-135 (D50). Owner (card, 2026-10-17): santi comments are cramped;
wants a collapsed composer "Add a comment…" with quick-reply chips and a keyboard hint, an expanded
composer with toolbar and Save/Cancel, each comment with avatar, name, relative time, a body with
comfortable spacing, and actions. Clean room: never copy quick-reply texts.

Facts today: `web/src/widgets/issue-detail/issue-comments.tsx` lists comments oldest first with
avatar, name, relative time and the Markdown body, and a composer that becomes the SAN-135 editor;
the API has list and create only (no edit, delete, reactions, replies). SAN-76 owns comment edit in
its scope list; SAN-94 owns the Activity tabs (All, Comments, History, Work log).
