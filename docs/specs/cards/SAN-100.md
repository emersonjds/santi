Owner: "EMERSON JUNIOR DANIEL SILVA" wraps to two lines in the issue fields; show two names on one line.

## Questions

| # | Question | product | ux | ia | Winner (architect) |

| 1 | Short form | first + last word | first + last word | — | **First + last word**: "Emerson Junior Daniel Silva" → "Emerson Silva"; one word stays as is. |

## Acceptance

- Helper `shortName(name)` next to `initials` in `web/src/shared/lib/initials.ts`; `initials` uses first + last word. Cases: one word, two, four, extra spaces, all caps, mixed case, accents (Á, Ç).
- Every web surface listed by `ia` uses it, with the full name in `title`/`aria-label`; the members page and account menu header keep the full name.
- CLI text output (`santi issues show|list`, board, backlog, whoami stays full) uses the same rule in Rust; `--json` unchanged.
- One line everywhere at 375px and 1440px.
